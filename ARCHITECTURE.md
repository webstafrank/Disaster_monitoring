# KSA Rangeland Intelligence Hub — Architecture

On-prem disaster-monitoring platform. A user picks a **location** (ASAL county) and a
**disaster indicator** (NDVI, VCI, SPI, rainfall, flood). The frontend calls the API,
which pulls the indicator time-series, runs deterministic analytics, and asks the local
LLM service for a plain-language insight. Everything runs on one physical server.

## Two machine spaces

The insight is deliberately split:

- **Deterministic** (`services/api/app/analytics.py`): severity class, trend, anomaly.
  Same series in, same numbers out. Fully unit-tested, no model, no network.
- **Latent** (`services/llm`): the plain-language briefing, generated by local Claude
  Code from the deterministic numbers. Never invents figures; grounded in the analytics.

The API assembles both in `services/api/app/insight.py`.

## Services

```
                      Nginx (443, TLS)          [deploy/nginx.conf]
                       /        |        \
                      /         |         \
              frontend        api         geoserver
             (Next.js)     (FastAPI)      (WMS/WFS)
                              |   \            |
                              |    \           |
                            llm    stub/geoserver source
                       (Claude Code)          |
                                          PostGIS + rasters
```

| Service          | Dir              | Port | Role |
|------------------|------------------|------|------|
| frontend         | `app/`           | 3000 | Next.js UI, calls the API via `app/lib/api.ts` |
| api              | `services/api`   | 8000 | Contract endpoints + deterministic analytics |
| llm (narrative)  | `services/llm`   | 8100 | Shells to local Claude Code for insight text |
| geoserver        | (image)          | 8080 | Serves EO map layers (WMS/WFS) |
| db               | (image)          | 5432 | PostgreSQL + PostGIS |
| nginx            | `deploy/`        | 443  | TLS termination, single entry point |

Each service is an independent deploy unit with its own tests. See its README.

## Contract

`contracts/openapi.yaml` is the single source of truth. `contracts/types.ts` mirrors it
for the frontend; `services/api/app/schemas.py` mirrors it for the backend. The
`services/api/tests/test_contract.py` gate test fails if the served schema drifts.

Endpoints: `GET /health`, `GET /locations`, `GET /indicators`,
`GET /observations`, `POST /insight`.

## Data source

Selected by `DATA_SOURCE`:
- `stub` (default) — deterministic placeholder series, tagged `source: "stub"` in every
  response so it is never mistaken for real data. Lets the whole loop run today.
- `geoserver` — the real feed. Adapter scaffolded in `services/api/app/sources/geoserver.py`,
  `get_series` to be implemented once the GeoServer URL, workspace, and layer mapping land.

The catalog (which counties and indicators exist) is shared across sources
(`services/api/app/sources/catalog.py`); only the values differ.

## Testing lanes

- **Gate** (free, deterministic, < 2s, every commit): `./scripts/gate.sh`. Enable the
  pre-commit hook with `git config core.hooksPath .githooks`.
- **Eval** (paid, periodic, before ship + nightly): `services/*/evals`. Runs real Claude
  Code and scores narrative quality against a threshold; skips cleanly when the model is
  unavailable.

## Run locally

```bash
# backend (from repo root, using the local venv)
DATA_SOURCE=stub .venv-test/bin/python -m uvicorn app.main:app --app-dir services/api --port 8000
LLM_MODE=claude .venv-test/bin/python -m uvicorn app.main:app --app-dir services/llm --port 8100

# frontend
npm run dev   # http://localhost:3000, NEXT_PUBLIC_API_BASE defaults to /api
```

## Deploy (server)

```bash
cp .env.example .env    # fill in secrets, never commit
git config core.hooksPath .githooks
./deploy.sh             # pull, build, up, health-check
```

Server prep: install Docker + Compose, provision TLS certs into `deploy/certs/`, and
authenticate the `claude` CLI for the llm service (host run or mounted config). See the
best-practices notes and `services/llm/README.md`.
